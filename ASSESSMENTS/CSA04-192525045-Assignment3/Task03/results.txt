5. CONCLUSION
-------------------------------------------------------------------------------
Modern operating systems (Linux, Windows, macOS) rely primarily on **Paging (Flat Memory Model)**
rather than pure segmentation because:
1. Paging completely eliminates the catastrophic external fragmentation that plagues segmentation.
2. Paging eliminates expensive physical memory compaction (which halts the system to copy megabytes).
3. Linux achieves modular protection through Virtual Memory Areas (VMAs) tracked in software,
   retaining the logical benefits of segmentation while enjoying the hardware simplicity of paging.
