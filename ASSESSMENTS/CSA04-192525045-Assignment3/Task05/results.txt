4. ENGINEERING DECISION FOR WEB SERVER
-------------------------------------------------------------------------------
Recommendation: **Clock (Second-Chance) Algorithm**.
Justification:
1. Exact LRU requires updating a timestamp or moving list nodes on EVERY memory access,
   incurring severe CPU and memory bus contention on a high-concurrency web server.
2. Clock algorithm achieves within 1.0% to 1.9% of exact LRU page fault performance.
3. Clock relies on a single hardware Reference Bit set by the MMU on access,
   executing eviction decisions in O(1) amortized time without locking memory structures.
